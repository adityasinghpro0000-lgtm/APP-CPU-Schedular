PROJECT

CPU Scheduling Simulatorwith Integrated Job Simulator

21CSC203P

This web-based simulator helps visualize how operating systems schedule processes using real-world algorithms such as FCFS, SJF, and Round Robin. Users can configure workloads, compare execution order, and analyze waiting time, turnaround time, and process efficiency through interactive charts and metrics.

  • Interactive process configuration
  • Algorithm comparison with Gantt chart output
  • Performance metrics and scheduling insights
